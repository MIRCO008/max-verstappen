# Max Verstappen — Sitio de fan

Sitio estático con la biografía, estadísticas, trayectoria, rivalidad 2021, circuitos, galería y minijuegos de Max Verstappen.

## Páginas

- `index.html` — página principal (dashboard).
- `galeria.html` — galería de fotos con carrusel de Bootstrap 3.
- `juegoss.html` — página secundaria de minijuegos.

## Tecnologías

- HTML5, CSS3 y JavaScript (vanilla).
- Bootstrap 3.4.1 + jQuery 3.7.1 (solo para el carrusel de la galería).

## Contenido multimedia

Las fotos, videos y el audio están en `max_imagenesyvideos/`.
